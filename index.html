01 · Inicio

¿Qué resuelve esta herramienta?

Apoya la planificación de recursos de cuatro unidades municipales. El sistema lineal representa relaciones de coordinación entre áreas y necesidades presupuestarias ponderadas. Los valores iniciales son hipotéticos y sirven para fines didácticos; no representan el presupuesto oficial del Gobierno Autónomo Municipal de La Paz.

PROBLEMA

Distribución coordinada

Estimar niveles de asignación para vialidad, alumbrado, residuos y áreas verdes considerando interdependencias operativas.

MÉTODO

GCP con Jacobi

Resolver Ax = b con un precondicionador diagonal y contrastar con Gradientes Conjugados sin precondicionar.

02 · Caso de estudio

Planificación de cuatro servicios municipales

En una ciudad como La Paz, las unidades operativas requieren coordinar recursos para mantener servicios básicos. Una modificación en una unidad puede afectar las necesidades de otras: por ejemplo, la intervención vial puede coordinarse con alumbrado o con la recolección de residuos.

03 · Formulación matemática

Sistema lineal Ax = b

El modelo usa cuatro ecuaciones y cuatro incógnitas. Cada coeficiente aᵢⱼ expresa el peso de la relación entre la unidad i y la variable de asignación j dentro del modelo normalizado.

A · x = b    con   A = Aᵀ   y   xᵀAx > 0 para todo x ≠ 0

La simetría representa una interacción recíproca entre pares de unidades. La definición positiva garantiza una energía cuadrática positiva y es una condición necesaria para aplicar GC/GCP en este problema.

Interpretación de coeficientes

Los elementos diagonales aᵢᵢ representan la respuesta propia de cada unidad; los elementos fuera de la diagonal aᵢⱼ = aⱼᵢ representan el acoplamiento entre dos unidades. Los términos bᵢ recogen la presión o necesidad ponderada de cada servicio. No deben leerse como montos presupuestarios directos.

05 · Métodos numéricos

¿Qué hace cada algoritmo?

Solución de referencia

Se utiliza eliminación de Gauss con pivoteo parcial. Para este sistema pequeño permite obtener una solución de referencia independiente de los métodos iterativos.

Ax = b → xref

Gradientes Conjugados (GC)

Parte de x₀, calcula el residuo r = b − Ax y construye direcciones conjugadas. Actualiza x hasta alcanzar la tolerancia relativa.

αₖ = (rₖᵀrₖ)/(pₖᵀApₖ)

GCP con Jacobi

Resuelve Mzₖ = rₖ con M = diag(A). Las direcciones se construyen usando zₖ, buscando mejorar la convergencia cuando existe mal escalamiento diagonal.

M = diag(a₁₁, …, aₙₙ)

Secuencia del algoritmo GCP

1
Inicialización: elegir x₀ y calcular r₀ = b − Ax₀.
2
Precondicionar: resolver Mzₖ = rₖ. Para Jacobi, zᵢ = rᵢ/aᵢᵢ.
3
Dirección: p₀ = z₀; luego pₖ₊₁ = zₖ₊₁ + βₖpₖ.
4
Tamaño de paso: αₖ = (rₖᵀzₖ)/(pₖᵀApₖ).
5
Actualizar: xₖ₊₁ = xₖ + αₖpₖ y rₖ₊₁ = rₖ − αₖApₖ.
6
Parada: finalizar cuando ||rₖ||₂/||b||₂ < tolerancia o se alcance Nmáx.

En el GC simple se usa zₖ = rₖ. En ambos métodos se controla el residuo relativo. La implementación incluye protección ante divisiones inválidas y matrices no aptas.

08 · Conclusiones y referencias

Interpretación técnica y financiera

Conclusiones del modelo

  • Un sistema matricial permite representar de forma simplificada la coordinación entre unidades municipales.
  • El escenario ideal permite observar la convergencia en condiciones numéricas favorables.
  • El escenario de estrés modifica las necesidades ponderadas para representar presiones económicas; el cambio de solución debe interpretarse como una simulación.
  • El mal condicionamiento puede amplificar la sensibilidad de la solución ante perturbaciones. El precondicionador de Jacobi busca reducir el efecto del escalamiento diagonal desigual.
  • Una solución numérica no reemplaza la evaluación técnica, presupuestaria ni normativa de una entidad pública.

Limitaciones

Los datos y coeficientes son sintéticos. El modelo no incorpora ingresos municipales observados, ejecución presupuestaria, inflación oficial, deuda, restricciones de caja ni optimización con límites. Para un estudio aplicado se deben reemplazar los datos por fuentes verificables y validar el modelo con personal financiero.
